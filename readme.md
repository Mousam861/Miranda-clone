## Overview

The Miranda website clone is a responsive and interactive web application designed to replicate the original Niccolo Miranda website. It uses animations, smooth scrolling, and modern CSS techniques to deliver a seamless user experience.

---

## Features

- Smooth scrolling using Locomotive Scroll.
- Interactive animations powered by GSAP (GreenSock Animation Platform).
- Fully responsive design for desktop and mobile devices.
- Hover effects on images and text.
- Multi-page layout with sections for navigation, featured works, and contact information.

---

## Technologies Used

- **HTML5**: For structuring the content.
- **CSS3**: For styling and layout.
- **JavaScript**: For interactivity and animations.
- **Locomotive Scroll**: For smooth scrolling effects.
- **GSAP (GreenSock Animation Platform)**: For advanced animations.

---
## Usage
Open the project in your browser to explore the interactive design.
Scroll through the pages to experience smooth scrolling and animations.
Hover over images and text to see hover effects.
